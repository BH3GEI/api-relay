    FAQ

    这是什么？

    这是一个 API 中转服务。你可以用统一的地址和 Key 访问多家 AI 模型，无需分别注册各家服务。

    支持 streaming 吗？

    支持。在请求中加入 "stream": true 即可获得流式响应。

    支持哪些 API 格式？

    支持以下端点：

    • /v1/chat/completions — 文本对话（OpenAI 格式，支持 Kimi / Claude / Gemini）

    • /v1/responses — 文本对话（OpenAI Responses 格式，Codex 用）

    • /v1/messages — 文本对话（Anthropic 格式，Claude Code 用）

    • /v1/messages/count_tokens — 计算 token 数（Anthropic 格式）

    • /v1/files — 文件上传（用于图片/视频理解，支持 Kimi）

    • /v1/images/generations — 图片生成（支持 Imagen 4.0）

    • /v1/videos/generations — 视频生成（支持 Veo 2.0 / 3.0）

    支持图片上传吗？

    支持两种方式：1) 将图片 base64 编码后直接放在消息中（data:image/png;base64,...）；2) 先通过 /v1/files 上传文件，再用返回的 file ID（ms://FILE_ID）引用。单次请求最大 100MB。

    和直接调用官方 API 有什么区别？

    对你的代码来说没有区别——请求和响应格式完全一样，只是换了地址和 Key。

    API Key 安全吗？

    你的 Key 只用于本服务的身份验证，不会被发送到任何上游服务商。请妥善保管，不要分享给他人。

    网页上的功能能用 API 调吗？

    都可以，带上 API Key（Authorization: Bearer sk-…）即可：

    • GET /v1/user/usage?period=day|month|year&tz=480 — 用量（按小时/天/月分桶，tz 是时区偏移分钟数）

    • GET /v1/quota — 个人限额和号池余量

    • GET /v1/user/api-key，POST /v1/user/api-key/refresh — 查看 / 更换 API Key（旧 Key 立刻失效）

    • PUT /v1/user/password — 改密码，body：{"current_password": "…", "new_password": "…"}

    • GET /v1/user/config — 应该填的 Base URL
