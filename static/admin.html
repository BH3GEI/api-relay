开始使用

  1. 在「服务商」页添加一家模型服务商：名称（如 kimi）、OpenAI Base URL，有 Anthropic 兼容地址的也填上（Claude Code 走这个）。
  2. 点该服务商的「Key」，填入你自己在服务商处申请的 API Key。可以填多把，数字小的优先，出问题自动换下一把。
  3. 「模型」页会自动同步模型列表。可以再建一个模型组（如 auto = 包月套餐模型 → 按量计费模型），客户端选组名即可按顺序回退。
  4. 回到首页，复制你的 Base URL 和 API Key，按首页的说明填进 Claude Code、Codex、Cherry Studio 等客户端。

本应用不附带任何服务商的 Key，所有 Key 只保存在你自己的微服上。

公网访问（Cloudflare Tunnel）

让 API（仅 /v1/…）不装懒猫客户端也能从公网访问；网页和管理后台仍需懒猫登录。
在 Cloudflare 中：Zero Trust → Networks → Tunnels → Create a tunnel（cloudflared）→ 复制 token。 再添加一个公网主机名（例如 relay.example.com），服务填 http://localhost:3001。

此版本没有 cloudflared 或公网监听。
