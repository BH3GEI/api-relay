Public Access (Cloudflare Tunnel)

Makes the API (/v1/… only) reachable from the internet without the LazyCat client. The pages and admin stay behind LazyCat sign-in.
In Cloudflare: Zero Trust → Networks → Tunnels → Create a tunnel (cloudflared) → copy its token. Then add a public hostname (e.g. relay.example.com) with service http://localhost:3001.

This build has no cloudflared or no public listener.
